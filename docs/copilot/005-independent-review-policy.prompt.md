# Mandatory post-task verification policy

After EVERY Copilot Agent task: independently review all changed files and relevant configuration, run a clean build and applicable tests, check behavior against phase acceptance criteria, and record factual evidence, errors, fixes, and any remaining gates in docs/PROGRESS.md and the relevant phase Markdown file. Copilot completion is not acceptance. Do not advance phases or flash without verified results and necessary user approval. Follow AGENTS.md. Any detected defects require a Copilot follow-up fix task and a repeated independent review.
